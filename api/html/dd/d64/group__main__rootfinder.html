Title

Create a solver for rootfinding problems

Returns a Function that solves a system of nonlinear equations g(x, p) = 0 for x, given the parameters p and an initial guess for x. The problem is given as a dictionary with fields "x" (unknowns, dense column vector), "g" (residual, dense column vector of the same size) and optionally "p" (parameters); any other field name is an error. The returned Function has inputs x0 (the guess) and p, and output x (see rootfinder_in and rootfinder_out). Omitted inputs are zero.

More generally, the problem is given as a Function [y0, y1, ..., yi, ..., yn] = F(x0, x1, ..., xj, ..., xm) where input xj is unknown and output yi is the residual that must be zero. The result is [y0, y1, ..., xj, ..., yn] = G(x0, x1, ..., xj_guess, ..., xm): the unknown input is replaced by a guess (its name gets a "0" suffix) and the residual output is replaced by the solution (named like the unknown input); the other inputs and outputs are passed through. By default j = 0 and i = 0; options "implicit_input" and "implicit_output" select other indices. xj and yi must be dense column vectors of the same size and d(yi)/d(xj) must be structurally and numerically invertible: a structurally rank-deficient Jacobian is an error at construction, a singular one makes the plugin fail.

The call can be embedded in an MX expression and differentiated: derivatives follow from the implicit function theorem, using the linear solver chosen with "linear_solver". "error_on_fail" defaults to true: a solve that does not converge raises; with false the last iterate is returned and stats() reports "success" and "return_status".

Options common to all plugins (the plugin options follow in the tables below):

  • "implicit_input", "implicit_output": indices j and i above (default 0).
  • "linear_solver", "linear_solver_options": Linsol plugin for the Newton steps and the sensitivities (default "qr").
  • "jacobian_function": user-supplied Function for d(yi)/d(xj) (generated by default).
  • "constraints": list with one entry per unknown, 0 (default) for no constraint, 1 for >= 0, -1 for <= 0, 2 for > 0, -2 for < 0; only honored by plugins that support it (e.g. kinsol), ignored by newton.
  • "expand", "print_time", "verbose", "common_options", "specific_options": as for nlpsol.
