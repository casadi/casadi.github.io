Detailed Description

Black-box numerical evaluation of an ONNX model.

A model is evaluated by a runtime backend (e.g. ONNX Runtime) selected by name; the graph internals are opaque to CasADi. Construct one through the GraphBuilder facade:

Function f = GraphBuilder("model.onnx").create("net");
std::vector<DM> res = f(DM(...));

These free functions query and manage the runtime backend plugin registry.

Extra doc: https://github.com/casadi/casadi/wiki/L_2j7
