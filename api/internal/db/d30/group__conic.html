Detailed Description

Create a QP solver

Returns a Function that solves the convex quadratic program (QP)

min          1/2 x' H x + g' x
x

subject to
LBA <= A x <= UBA
LBX <= x   <= UBX

resize(Q x, np, np) + P >= 0 (psd)

with :
H sparse (n x n) positive definite
g dense  (n x 1)
A sparse (nc x n)
Q sparse symmetric (np^2 x n)
P sparse symmetric (np x nq)

n: number of decision variables (x)
nc: number of constraints (A)
nq: shape of psd constraint matrix

Whether an indefinite H is detected depends on the plugin: some raise an error, others return a stationary point. Second-order cone constraints can be added as psd constraints through the helper function soc: || x ||_2 <= y is equivalent to soc(x, y) being psd, with soc(x, y) = [y*I x; x' y] (Schur complement). Only some plugins support psd constraints.

conic is the low-level form: the problem is given by the sparsity patterns of "h" and "a" (and optionally "q", "p"), and the numerical values are passed at every call. At least one of "h" and "a" is needed; a missing "h" means a linear objective (LP) and a missing "a" means no linear constraints. "h" must have a square, symmetric sparsity pattern. Inputs are h, g, a, lba, uba, lbx, ubx, x0, lam_x0, lam_a0, q, p (see conic_in); outputs are x, cost, lam_a, lam_x (see conic_out). Omitted inputs default to -inf (lba, lbx), +inf (uba, ubx) or 0.

qpsol is the symbolic form: a dictionary with fields "x" (dense vector), "f" (scalar), optionally "p" (parameters) and "g" (dense vector), as for nlpsol. The matrices H, g, A and the constant terms are obtained by symbolic differentiation and evaluated at every call at x0 and p; "f" must be quadratic and "g" linear in "x", this is NOT checked: other expressions are silently replaced by their second order (f) or first order (g) expansion around x0. The returned Function has the nlpsol input and output scheme (x0, p, lbx, ubx, lbg, ubg, lam_x0, lam_g0 -> x, f, g, lam_x, lam_g, lam_p); lam_p is always NaN.

Multiplier convention as for nlpsol: a multiplier is negative when the lower bound is active and positive when the upper bound is active, such that H x + g + A' lam_a + lam_x = 0.

To silence a solver, set "print_time" False plus the plugin's own options, e.g. {"print_iter": False, "print_header": False, "print_info": False} for qrqp or {"printLevel": "none"} for qpoases (its copyright notice is printed regardless).

Options common to all plugins ("error_on_fail" defaults to true for QP solvers, so a failed solve raises; with false the plugin result is returned and stats() reports "success"):

  • "discrete": list of n booleans marking integer variables; needs a plugin with integer support (e.g. cplex, gurobi, highs), otherwise an error at construction.
  • "equality": list of nc booleans hinting which linear constraints have equal bounds.
  • "print_problem": print the numerical problem data at every call (default false).
  • "print_time": print a timing table after each call (default false).
  • "expand" (qpsol only): convert an MX problem to SX (default false).
  • "sens_min_lam", "sens_linsol", "sens_linsol_options": used when differentiating the solver Function (a call embedded in an MX expression): a bound is treated as active when its multiplier exceeds "sens_min_lam" in magnitude (default 0) and the KKT system is solved with linear solver "sens_linsol" (default "qr"). The plugin options follow in the tables below.

>>> x = SX.sym("x"); y = SX.sym("y")
>>> qp = {"x": vertcat(x, y), "f": x**2 + y**2 + x*y - 3*x, "g": x + y}
>>> opts = {"print_iter": False, "print_header": False, "print_info": False}
>>> S = qpsol("S", "qrqp", qp, opts)
>>> S.name_in()
['x0', 'p', 'lbx', 'ubx', 'lbg', 'ubg', 'lam_x0', 'lam_g0']
>>> S.name_out()
['x', 'f', 'g', 'lam_x', 'lam_g', 'lam_p']
>>> sol = S(lbg=1, ubg=1, lbx=0)
>>> sol["x"], sol["f"]
(DM([1, 0]), DM(-2))
>>> sol["lam_g"], sol["lam_x"]
(DM(1), DM([0, -2]))
>>> sol["g"], sol["lam_p"].shape
(DM(1), (0, 0))
>>> S.stats()["success"], S.stats()["return_status"]
(True, 'success')
