casadi::UoutJournal Class Reference

Ipopt journal printing through casadi::uout() More...

#include <ipopt_uout_journal.hpp>

Detailed Description

uout() is thread_local, so the stream is looked up at every write rather than stored: a StreamJournal holding &uout() keeps pointing at the stream of the thread that created the solver memory, which is destroyed when that thread exits (e.g. a map(..., "thread") worker). The next solve on another thread then crashes in Journalist::FlushBuffer, even with printing disabled.

Shared by the ipopt and bonmin plugins (header-only).
